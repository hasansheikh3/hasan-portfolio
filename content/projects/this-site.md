The site you are reading is a static site generated by Hugo and deployed on
Netlify's free plan.

- Content is Markdown in a Git repository.
- Builds are fast because Hugo is a single binary with no runtime dependencies.
- Images are resized and converted to WebP during the build, which keeps pages
  light and bandwidth low.
